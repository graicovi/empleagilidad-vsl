# VSL reducida — variante aislada

Esta carpeta contiene una versión de validación de la VSL reducida y de su formulario en una página independiente.

- `vsl_pagina_reducida_v1.html`: Hero, problema y método.
- `vsl_formulario_reducido_v1.html`: formulario de postulación.
- `vsl_hero_referencia_aprobada.png`: imagen del hero utilizada por esta variante.

La VSL principal del repositorio permanece sin cambios. Para abrir esta versión publicada, navega a `vsl-reducida/vsl_pagina_reducida_v1.html`.
