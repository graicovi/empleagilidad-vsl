# Empleagilidad VSL

Landing page de video de ventas para el programa Empleagilidad, orientado a profesionales con experiencia que necesitan reposicionarse ante los cambios del mercado y la inteligencia artificial.

![Vista completa de la VSL](preview.png)

## Ver el proyecto

Abre `index.html` en un navegador moderno. Es una página estática y no necesita instalación ni proceso de compilación.

## Contenido

- `index.html`: página completa de la VSL.
- `vsl_hero_referencia_aprobada.png`: imagen principal del video.
- `giancarlo_raicovi_doctor_cv.webp`: fotografía del autor y director del programa.
- `libro_empleagilidad_3d.png`: mockup tridimensional del libro.
- `preview.png`: captura de referencia de la página completa.

## Tecnología

HTML, CSS y JavaScript. Las animaciones de desplazamiento utilizan GSAP y ScrollTrigger mediante CDN.
